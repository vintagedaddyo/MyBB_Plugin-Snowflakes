
Snowflakes

Adds beautiful snowflakes to your board.

Author: Vintagedaddyo

This Plugin is perfect for winter. It adds snowflakes to your board with the option to turn the snowflakes on or off via the user cp

To install, just copy the files from the ZIP-archive into the right directory of your server and activate the Plugin in the admin control panel.

This is a MyBB plugin for the script created by:
https://www.go4u.de/snowflakes.htm

Compatibility
MyBB 1.8: Yes
